
# DentVision

## Dental X-Ray Visual Interpreter

### Project Description
DentVision is an image processing project that aims to transform panoramic dental X-ray images into clearer and more understandable 2D visualizations.

The main goal is to help dentists explain dental structures and treatment plans to their patients more effectively.

### Problem
Dental X-rays contain complex structures and grayscale details that can be difficult for patients to understand.

Although dentists can interpret these images, patients may have difficulty identifying which teeth or areas are being discussed.

This project aims to make dental X-rays easier to understand through patient-friendly visual representations.

### Methodology
The planned system will follow five main steps:

1. **Image Upload:** The user uploads a panoramic dental X-ray.
2. **Image Enhancement:** Contrast enhancement and noise reduction are applied to improve image clarity.
3. **Image Analysis:** Thresholding and contour detection are used to analyze different regions and boundaries.
4. **Segmentation:** Tooth regions are identified using image segmentation techniques.
5. **2D Visualization:** The extracted information is used to create a simplified and patient-friendly dental illustration.

### Technologies
- **Python:** Main programming language.
- **OpenCV:** Image processing and enhancement.
- **NumPy:** Pixel analysis and numerical operations.
- **Pillow:** Creating and editing 2D dental visualizations.
- **Streamlit:** Developing the user interface.

### Expected Result
The expected result is a working prototype that allows users to upload panoramic dental X-rays, process the images, identify tooth regions, and generate clearer 2D visual representations.

The project aims to support patient education and improve communication between dentists and patients.

The system is intended for visualization purposes, not medical diagnosis. Generated illustrations will not represent exact reconstructions of a patient's teeth.
